# AI Company Multi-Agent Project

이 저장소는 AI 회사형 멀티 에이전트 협업을 위한 문서 템플릿과 워크플로우를 정리한 예시 프로젝트다.

## 폴더 구성
- AGENTS: 각 AI 에이전트의 역할과 System Prompt를 저장한다.
- RULES: 공통 개발 규칙과 운영 규칙을 저장한다.
- PROJECT: 프로젝트 관리 템플릿과 진행 상황을 관리한다.
- DOCUMENTS: API, DB, 아키텍처, 프롬프트, 회의록 템플릿을 저장한다.
- MEMORY: 의사결정, 실수, 배운 점을 기록한다.

## 추천 워크플로우
1. CEO가 프로젝트 목표와 우선순위를 정한다.
2. PM이 작업을 분해하고 일정과 담당자를 배정한다.
3. Research가 시장과 기술 조사 결과를 정리한다.
4. Design이 UX/UI를 설계한다.
5. Frontend, Backend, AI가 구현한다.
6. QA가 테스트와 품질 검증을 수행한다.
7. DevOps가 배포 및 운영 준비를 한다.
8. Documentation이 문서를 정리한다.
9. CEO가 최종 승인한다.

## 사용 방법
- 새 프로젝트를 시작할 때 각 폴더의 템플릿을 복사해 사용한다.
- 에이전트별 역할은 AGENTS 폴더의 문서를 참고한다.
- 개발 중 규칙 위반 여부는 RULES 폴더를 기준으로 점검한다.
- 프로젝트 진행 상황은 PROJECT 폴더에 기록한다.
- 중요한 결정과 학습 내용은 MEMORY 폴더에 남긴다.
