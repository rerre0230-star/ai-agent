# 🎙️ 음성 비서 사용법

사용자가 말하면 → AI가 텍스트로 인식 → 요청한 일을 실행하는 프로그램입니다. 규칙 기반이라 **무료이고 API 키가 필요 없습니다.**

## 할 수 있는 일

| 말하면 | 하는 일 |
| :---- | :---- |
| "내일 오후 3시에 치과 예약 잡아줘" | 캘린더 일정(.ics 파일) 생성 |
| "7월 25일 10시 30분에 팀 회의 잡아줘" | 날짜·시간 지정 일정 생성 |
| "파이썬 검색해줘" / "손흥민 알려줘" | 브라우저로 검색 결과 열기 |
| "지금 몇 시야" | 현재 시간 알려주기 |
| "오늘 며칠이야" | 오늘 날짜·요일 알려주기 |
| "안녕" | 인사·안내 |
| "종료" | 프로그램 끝내기 |

## 실행 방법

### 1단계 — 그냥 실행 (설치 없이 텍스트 모드로 바로 테스트)

```
python voice_assistant.py --text
```

키보드로 명령을 입력하며 모든 기능을 바로 확인할 수 있어요.

### 2단계 — 음성으로 쓰기 (마이크 입력)

아래 라이브러리를 설치하면 실제로 말로 대화할 수 있습니다.

```
pip install SpeechRecognition pyttsx3 pyaudio
```

- Windows: 위 명령 그대로
- Mac: `brew install portaudio` 먼저 실행 후 `pip install ...`
- Linux: `sudo apt install python3-pyaudio`

설치 후 실행:

```
python voice_assistant.py
```

마이크에 대고 말하면 인식합니다. (구글 무료 음성인식을 쓰므로 인터넷은 필요) 응답은 콘솔 자막과 함께 음성(pyttsx3)으로도 항상 함께 나와요.

## 캘린더 일정은 어떻게 등록되나요?

일정을 잡으면 프로그램 폴더 안 `events/` 에 `.ics` 파일이 생깁니다.

- 그 파일을 **더블클릭**하면 기본 캘린더(애플/아웃룩)에 바로 들어갑니다.
- 구글 캘린더는 설정 → **가져오기(Import)** 에서 그 파일을 선택하면 등록됩니다.

## 구조 (나중에 고치고 싶을 때)

프로그램은 4개 계층으로 나눠져 있어 원하는 부분만 바꾸기 쉽습니다.

1. **입출력** — 듣기(`listen_voice`) / 말하기(`speak`)
2. **의도 파악** — `detect_intent` (여기에 키워드를 추가하면 새 명령 인식)
3. **실행** — `handle_calendar`, `handle_search` 등
4. **메인 루프** — `main`

## 더 똑똑하게 만들고 싶다면

지금은 정해진 키워드를 알아듣는 규칙 기반이라 자유로운 잡담에는 약합니다. 자연스러운 대화가 필요하면 `detect_intent` 대신 OpenAI/Claude API를 붙이면 됩니다.
