# Project Overview

## 프로젝트 소개
이 프로젝트는 AI 회사형 멀티 에이전트 협업 구조를 실험하고 관리하기 위한 템플릿 프로젝트다.

## 목표
- 에이전트별 역할 분담을 명확히 한다.
- 개발 규칙과 문서 체계를 표준화한다.
- 프로젝트 관리와 의사결정 기록을 체계적으로 남긴다.

## 핵심 기능
- 역할 기반 에이전트 문서 관리
- 개발 규칙 및 워크플로우 정의
- 프로젝트, 문서, 메모 템플릿 제공

## 타깃 사용자
- AI 에이전트 협업을 설계하는 팀
- 스타트업 또는 프로젝트 관리자
- 개발자 및 기술 문서 작성자
